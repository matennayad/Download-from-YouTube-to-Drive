# Download-from-YouTube-to-Drive

## סקריפטים למתמחים טופ (Tampermonkey)

### תיקון ZI ל-ZIP במתמחים טופ - הסקריפט המלא
תיקון סיומות ZIP ו-APK בהורדה ובהעלאה, תצוגת קבצים, תמונות וקישורים בסוף כל פוסט, באנרים לקישורים, ספויילרים בהמשך השורה, והסרה והוספה של כוכביות בקישורים לדרייב, לג'מבו מייל ול-send.magicode.me.

**[להתקנה ישירה לחצו כאן](https://raw.githubusercontent.com/matennayad/Download-from-YouTube-to-Drive/main/Mitmachim%20ZI%20to%20ZIP.user.js)**

### מסיר ומוסיף כוכב*ות
השרת של מתמחים לא שומר קישורים לדרייב, לג'מבו מייל ול-send.magicode.me, ולכן מעלים אותם עם כוכביות בתוך הקישור.
- **בשליחת פוסט** - מדביקים קישור רגיל, והסקריפט מכניס לתוכו כוכביות לפני שהוא נשלח לשרת. מי שאין לו את הסקריפט רואה את הכוכביות ומוחק אותן מהכתובת בעצמו.
- **בקריאה** - קישור שנשמר עם כוכביות (`*` `#` `@` `&`) מוצג ונפתח בלי הכוכביות, וגם דף שגיאה שנפתח מקישור כזה עובר מיד לקובץ האמיתי.

**[להתקנה ישירה לחצו כאן](https://raw.githubusercontent.com/matennayad/Download-from-YouTube-to-Drive/main/Mitmachim%20Star%20Links.user.js)**
