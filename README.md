# Download-from-YouTube-to-Drive

## סקריפטים למתמחים טופ (Tampermonkey)

### תיקון ZI ל-ZIP במתמחים טופ - הסקריפט המלא
תיקון סיומות שבורות בהורדה (ZI ל-ZIP, AP ל-APK, JA ו-AR ל-JAR ועוד), העלאת ZIP כ-ZIP אמיתי, תצוגת קבצים, תמונות וקישורים בסוף כל פוסט, באנרים לקישורים, ספויילרים בהמשך השורה, והסרה והוספה של כוכביות בקישורים לדרייב ולגוגל דוקס/טפסים, לג'מבו מייל ול-send.magicode.me.

**[להתקנה ישירה לחצו כאן](https://raw.githubusercontent.com/matennayad/Download-from-YouTube-to-Drive/main/Mitmachim%20ZI%20to%20ZIP.user.js)**

### מסיר ומוסיף כוכב*ות
השרת של מתמחים לא שומר קישורים לדרייב ולגוגל דוקס/טפסים, לג'מבו מייל ול-send.magicode.me, ולכן מעלים אותם עם כוכביות בתוך הקישור.
- **בשליחת פוסט** - מדביקים קישור רגיל, והסקריפט מכניס לתוכו כוכביות לפני שהוא נשלח לשרת. מי שאין לו את הסקריפט רואה את הכוכביות ומוחק אותן מהכתובת בעצמו.
- **בקריאה** - קישור שנשמר עם כוכביות (`*` `#` `@` `&`) מוצג בלי הכוכביות, אבל הכתובת שלו במתמחים נשארת שבורה. בלחיצה עוברים לקישור השבור, ושם הוא מתקן את עצמו ועובר לקובץ האמיתי.

**[להתקנה ישירה לחצו כאן](https://raw.githubusercontent.com/matennayad/Download-from-YouTube-to-Drive/main/Mitmachim%20Star%20Links.user.js)**
